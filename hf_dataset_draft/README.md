# KwExt Bilibili Video Title Annotations

This dataset is a versioned, model-assisted annotation set for the KwExt
keyword extraction project. It currently contains 3,000 Chinese Bilibili video
titles from annotation stages `video_title_zh_001` through
`video_title_zh_003`.

The release is intended for early experiments with:

- extracting title-grounded keywords and ranking their importance;
- broad semantic tags for retrieval and RAG metadata;
- dense tag classification and candidate-ranker training.

The labels are weak labels generated by a Qwen model and have not been fully
reviewed by humans. They must not be treated as gold annotations.

## Files

- `data/bilibili_video_title_annotations.jsonl`: one normalized record per
  title;
- `quality_report.json`: counts and known quality flags;
- `manifest.json`: schema version, row count, source and SHA-256 checksum.

## Record schema

Each JSONL record contains:

```json
{
  "id": "bilibili-masterpiece-002163",
  "title": "一 日 一 恶",
  "language": "zh",
  "source": "bilibili-masterpieces",
  "category": "video_title",
  "platform_category": "同人·手书",
  "stage": "video_title_zh_001",
  "source_metadata": {
    "bvid": "BV...",
    "tid": 153,
    "tname": "同人·手书",
    "view": 12345
  },
  "annotation": {
    "keywords": [],
    "broad_tags": [],
    "dense_tags": [],
    "title_type": "series_episode",
    "signals": {},
    "uncertain": []
  },
  "quality": {}
}
```

`annotation.keywords` may contain two kinds of keyword:

- `span_type: "exact"`: `surface` is an exact substring of the title;
- `span_type: "inferred"`: a semantically useful keyword inferred from the
  title; `surface` may be `null` because it is not a literal title span.

Keyword records include `score`, `importance` (1--3), `rank`, `type`, and
`normalized`. Broad and dense tags are title-level categories and do not have
to be literal words from the title. Dense tags include `name`, `normalized`,
`type`, `score`, `evidence`, and `evidence_source`.

## Data composition and quality

The v0.1 snapshot contains one thousand records from each of the three listed
Chinese Bilibili stages. The first stage predates dense-tag annotation, so its
`dense_tags` array is normalized to `[]`; later stages contain dense tags when
the model produced them. `quality.dense_tags_available` records this per row.

The release preserves model output rather than silently rewriting it. Rows
with an out-of-range importance value are listed in `quality_report.json` and
marked with `quality_status: "review"`. Filter those rows before using
`importance` as a supervised target.

## Provenance

The source dataset is
[`wencan2024/bilibili-masterpieces`](https://huggingface.co/datasets/wencan2024/bilibili-masterpieces).
Its dataset card documents Bilibili metadata fields including `bvid`, `tid`,
`tname`, `title`, `desc`, and `view`, and identifies the source dataset as
CC0-1.0. This release keeps the title and lightweight source identifiers and
omits the original description field.

The annotation layer was produced by the KwExt staged annotation pipeline
using a Qwen model. It is an automatically generated research artifact, not a
claim that the source dataset's license also applies to the generated labels.
The final redistribution license for the annotation layer is intentionally
left pending until it is decided by the project owner.

## Versioning

`v0.1` is an immutable snapshot of stages `video_title_zh_001`--
`video_title_zh_003`. Later annotation stages should be published as a new
release instead of changing this file in place. Use `manifest.json` and its
SHA-256 value to verify a downloaded snapshot.
