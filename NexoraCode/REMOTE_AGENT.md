# NexoraCode 本地上下文与远程连接

保留现有桌面界面和本地 AgentLoop。网页与 Android 发送任务到在线电脑，电脑调用模型 API 并执行工具；云端只负责身份验证和即时转发。

## 使用流程

1. 更新云端 ChatDBServer 和 NexoraWeb。反向代理须允许 `/ws/nexoracode` 的 WebSocket 升级，后端进程需要加载新代码。
2. 登录网页，在侧栏 Projects 中生成配对码。
3. 重启更新后的 NexoraCode，打开设置中的远程连接，填写云端地址、电脑名称和配对码，然后配对。
4. 网页 Projects 或 Android 侧栏“电脑项目”中选择在线电脑，再选择会话或发送新任务。手机和网页应登录生成配对码的同一个账号。
5. 电脑断线后无法读取历史。电脑重新连接后可补取执行事件；电脑进程重启时，未完成任务标记为中断，不会自动重新执行。

远程项目任务只能使用电脑上已有会话登记的项目目录。首次项目授权仍在电脑进行。配对凭据只存电脑本地，界面与远程配置接口不返回凭据。可在网页撤销配对，或在电脑设置中关闭远程连接。

## 上下文管理

按模型上下文窗口和输出预留预算，在本地压缩已完成的旧轮次；当前用户输入和工具调用结果保持完整。原始历史不删除，可通过 `local_context_length`、`local_context_search`、`local_context_read` 查询。

输入预算采用保守估算并根据模型实际输入用量校准。单个不可拆分轮次超出预算、摘要被截断或工具调用配对不完整时明确报错，不会静默截断历史。压缩模型用量单独保存在本地并显示在用量详情中。

## 数据与接口

- 电脑：`data/conversations` 内的历史及上下文状态、`data/task_events` 的执行日志、任务请求去重记录和 `data/remote_connection.json` 的连接凭据。
- 云端：设备身份与凭据哈希。配对码、连接和等待中的转发请求只在内存中，不持久化会话内容或执行事件。
- 云端接口：`/api/nexoracode/pair`、`claim`、`devices`、设备 `rpc` 和 `/ws/nexoracode`。
- 电脑任务接口：`/api/local/tasks`、任务 `events`、`cancel`。每个请求带固定 `request_id`，重试不会再次执行同一任务。

## 验证与待办

隔离测试使用临时配置和模拟模型，覆盖本地压缩、真实 WebSocket 转发、事件回放、权限边界、请求去重及短命令取消。网页完成构建和桌面/窄屏交互预览；Android 完成 ArkTS 编译。

上线前仍需验证真实模型长会话、生产反向代理与账号登录、Android 真机，以及电脑断网重连。尚未自动部署、制作桌面安装包或安装手机包。执行事件目前无自动清理策略；长期运行后的保留策略需要另行确定。后台常驻终端服务不随短命令取消而停止。
