Nexora

Connect / Remember / Know

自建的模型接入与知识平台。邮件、检索、网盘与代码执行， 都是可以拆开单独部署的组件。

进入 Nexora GitHub

Nexora

Web 平台

主服务 ChatDBServer 负责模型接入、对话、工具路由与知识检索。 接入 Volcengine、DashScope、OpenAI 等多家服务，在同一工作区里 管理对话、文件与知识库，并维护成员、用量与计划任务。

Provider 与模型
接入多个模型服务，维护模型参数，并按用户或角色配置可见范围。
对话与工具
集中管理会话；按需使用工具调用、联网搜索和知识检索，并查看调用记录。
文件、知识库与笔记
导入 Word、PDF、演示文稿等资料进行检索；共享知识内容，并把对话中的信息整理为笔记。
成员、任务与用量
管理成员权限和计划任务，查看 Token 用量、对话日志及平台运行统计。

NexoraCode

桌面端

运行在电脑本机，围绕选定的项目目录组织会话：查找和修改项目文件、 执行命令、预览本地页面。也可以从网页或手机远程发起任务。

按项目组织工作
将项目目录、相关会话和执行记录放在一起，便于继续处理同一项目。
本地开发工具
读取、搜索和修改项目文件，运行命令，并预览本地网页。
权限与确认
文件和命令操作遵循本地权限设置；遇到受限操作时，可以先查看请求再决定是否授权。
本地插件
插件可以增加开发工具、设置项和侧栏页面，用于接入自己的工作流程。
远程连接
完成账号配对后，从 Nexora 网页或 Android 选择在线电脑和已有项目发送任务， 任务由电脑端执行，执行事件同步回页面。
  1. 电脑端开启远程连接
  2. 使用同一账号完成配对
  3. 选择在线电脑和项目
  4. 查看任务执行记录

可拆卸组件

Components

各组件可独立部署、按需组合，主服务之外的模块不跑也可以正常使用。

NexoraMail
邮件服务，负责收发邮件，并向 LLM 提供发信、查看收件箱等工具；部署需要 25 端口和域名。
NexoraDB
基于 ChromaDB 的向量数据库，负责知识库的向量存储与检索，可切换不同的 embedding 模型。
NexoraNetdisk
文件存储服务，存放知识库相关的文档、图片等资源。
NexoraSearch
基于 Playwright 的轻量搜索服务，渲染网页并提取内容。

在本机运行

Install

Python 环境即可启动主服务，其余组件按需另行部署。

git clone https://github.com/Himpq/Nexora.git cd ChatDBServer pip install -r requirements.txt python server.py
