# Triage Labels

Canonical labels:

| 角色 | Label |
|---|---|
| 需要维护者评估 | `needs-triage` |
| 等待 reporter 补充信息 | `needs-info` |
| 描述完整，可交给 agent | `ready-for-agent` |
| 需要人类实现或产品判断 | `ready-for-human` |
| 不处理 | `wontfix` |

可选项目标签：

- `area:chatapp`
- `area:backend-contract`
- `area:docs`
- `area:ui-ux`
- `type:bug`
- `type:feature`
- `type:refactor`
- `type:test`

`area:ui-ux` 不代表可以把 UI/UX 提前到数据流稳定之前。
